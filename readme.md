# Express Loki Logging Integration

This repository demonstrates how to integrate **Loki** for centralized logging in an **Express** application, using **Docker** for containerization. It includes the setup of **Loki**, **Promtail** (for log forwarding), and an optional Grafana setup for visualizing logs.

## Prerequisites

Before getting started, make sure you have the following installed:
- **Docker** (and Docker Compose)
- **Node.js** (for running the Express app)
- **Grafana** (optional, for visualizing logs)
